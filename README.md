# Chat TCP/IP

Aplicación de chat cliente-servidor desarrollada en Java utilizando sockets TCP/IP.

## Características
- Comunicación en tiempo real mediante protocolo TCP/IP.
- Arquitectura cliente-servidor.
- Gestión de múltiples conexiones concurrentes.

## Requisitos
- Java JDK 17 o superior.
- IDE recomendado: IntelliJ IDEA.

## Ejecución
1. Inicia primero la clase principal del **Servidor**.
2. Ejecuta una o varias instancias de la clase **Cliente** para comenzar a chatear.
